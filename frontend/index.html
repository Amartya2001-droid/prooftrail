                Agent team

                Five named specialists work a project when you run the team. Verity re-verifies the ledger, Sleuth hunts anomalies, Mapper maps who wrote what, Scribe writes the plain-language proof narrative, and Trailboss coordinates them and merges their findings into one report. Every run is written into the signed ledger as it happens, so a run's findings are tamper-evident like everything else.
